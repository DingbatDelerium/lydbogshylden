# Lydbogshylden

En lille web-app (PWA) til danske lydbøger fra [LibriVox](https://librivox.org). Alle optagelser er doneret til public domain af frivillige oplæsere. Teksterne er frie efter dansk ophavsret (forfatter og oversætter døde for mere end 70 år siden, eller anonym udgivelse for mere end 70 år siden).

- Lyden hentes direkte fra archive.org. Intet lyd ligger i dette repo.
- "Gem til offline" lægger en bog på telefonen.
- Husker hvor man slap, bogmærker, sove-timer, fart.

Tak til dem, der skrev, oversatte og læste højt.
